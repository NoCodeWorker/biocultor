# Decisions

## ADR activos

- `ADR-001-programmatic-seo-content-system.md`: define la capa SEO programática y transaccional como sistema de contenidos server-first, reutilizable y orientado a intención.
- `ADR-002-editorial-evidence-policy.md`: define que la capa editorial del blog debe apoyarse en estudios y fuentes identificables para reforzar intención de compra sin claims no verificables.
- `ADR-003-blog-database-integrity.md`: protege los datos editoriales persistidos y evita sobrescribir imágenes manuales del dashboard.
- `ADR-004-editorial-dashboard-sync-contract.md`: obliga a que artículos, landings y servicios nuevos aparezcan en el dashboard correcto para edición visual.
- `ADR-005-editorial-visual-generation-policy.md`: define el estándar híbrido de imágenes WebP realistas con capa infográfica determinista, Quicksand y claims prudentes.
- `ADR-006-editorial-content-generation-contract.md`: contrato end-to-end para crear contenido con evidencia, copy, imagen, dashboard, SEO/GEO/AIO y validación coherentes.
